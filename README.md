# 財務藍圖 Future Ledger V3.1

可部署於 GitHub Pages 的純前端 PWA。資料只儲存在瀏覽器 localStorage。

## V3 功能
- 起始資產統一為 2026/12/31 月底
- 資產分類：現金流、台股與 ETF、公司認股、美元儲蓄險
- 美元儲蓄險可輸入美元金額、匯率、保費與增值率
- 每月固定支出與每年固定支出；年度項目自動平均分攤 12 個月
- 年終與兩次分紅均於指定月底入帳
- 買車、買房兩個獨立切換
- 買房可指定可動用資產來源，依現金流→台股與 ETF→公司認股→儲蓄險順序扣除
- 若資金不足，以負現金顯示缺口並在總覽提醒
- 月底資產明細、計畫支付來源、貸款餘額與資產價值均可追溯
- iOS/Android PWA Icon 與離線快取

## GitHub Pages
將此資料夾內容上傳至 Repository 根目錄，再至 Settings → Pages → Deploy from a branch → main / root。
