# Future Ledger

一個可部署在 GitHub Pages 的純前端個人財務規劃 PWA。

## 已完成
- 2026–2045 每月資產推估
- 現金、投資資產、儲蓄險、負債分開計算
- 月薪、年終、年度分紅、固定支出、每月投資與儲蓄險保費
- 基準／買車／買房／車＋房四種情境
- 車貸與房貸本息攤還
- 車輛折舊與房屋增值
- 每月「顯示更多」計算明細
- 本機 localStorage 儲存
- PWA 離線快取

## GitHub Pages 部署
1. 建立新的 GitHub repository。
2. 將本資料夾內所有檔案上傳到 repository 根目錄。
3. 到 Settings → Pages。
4. Source 選擇 Deploy from a branch。
5. Branch 選 main，資料夾選 /(root)。
6. 儲存後等待 GitHub Pages 網址生成。

## 注意
這是第一版原型。現在的收入與支出採固定規則；下一版可加入「逐年調薪」、「單次支出」、「每年不同分紅」、「多個投資帳戶」及「資料匯出／還原」。
